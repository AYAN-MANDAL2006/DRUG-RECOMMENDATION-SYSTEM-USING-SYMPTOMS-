About The Project

Project Title:

DRUG RECOMMENDATION SYSTEM BASED ON SYMPTOMS

Academic Context:

Developed as a B.Tech CSE (AI/ML) academic project to demonstrate the practical application of Natural Language Processing (NLP), Machine Learning (Scikit-learn), Relational Database Management (SQLite), and Web Development (Python Flask).

Technology Stack:

  • Backend Framework: Python 3, Flask
  • Data Processing: Pandas, NumPy
  • Natural Language Processing (NLP): Basic NLP (Tokenization, Lowercasing, Stopword Removal, Synonym Mapping, Term Extraction)
  • Machine Learning: Scikit-learn (TF-IDF Vectorizer + Multinomial Naive Bayes / Cosine Similarity)
  • Database: SQLite (Normalized relational database schema)
  • Frontend: HTML5, Vanilla CSS3 (Healthcare design system), Jinja2 Templates, JavaScript

Project Purpose:

The purpose of this project is to provide users with reliable EDUCATIONAL information about commonly used OTC medicines for basic symptoms. It allows users to express their symptoms in natural language and retrieve transparent match scores, educational precautions, and safety warnings.

🛡️ Academic Non-Diagnostic Notice: This software is strictly for academic research and educational evaluation. It is NOT a clinical diagnosis tool or automated prescription engine.
